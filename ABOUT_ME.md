## ProStock AI Project

### What It Is
ProStock AI is my flagship project—a professional LSTM-based deep learning model for predicting NSE (National Stock Exchange of India) stock movements. The model uses an ensemble approach combining:

- Single-stock LSTM: Individual stock prediction models
- Universal market bias: Nifty 50, S&P 500, USD/INR trends
- News sentiment: Text analysis of market-moving news
- 11 technical features: Moving averages, RSI, volume ratios

### Key Achievements
- Multi-horizon predictions: 1-day, 5-day, 10-day, 20-day forecasts
- Risk metrics: 95% VaR, Stop Loss, Take Profit, Annual Volatility
- Sentiment analysis: Positive/Neutral/Negative news classification
- Walk-forward validation: 3/3 folds, 66.67% directional accuracy
- Web UI: Tailwind CSS dark-mode interface at localhost:8000
- Hugging Face: Model card ready at samarulraj/indian-stock-lstm
- Git repository: Version-controlled with 16+ essential files

### Technology Stack
- Model: LSTM (TensorFlow/Keras) with ensemble approach
- Data: Yahoo Finance (yfinance) for NSE Indian stocks
- Features: 11 technical + macro features per prediction
- API: FastAPI with comprehensive endpoints
- UI: Tailwind CSS, dark-mode, glassmorphism design
- Deployment: Hugging Face Hub, local FastAPI server
- Version Control: Git with structured commit history
